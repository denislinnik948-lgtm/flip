# App Store listing — English

Character limits are Apple's. Counts are given so edits stay inside them.

## Name (30 max)

```
Flip Field
```

10 characters.

`FLIP` alone is taken — there is already a platform-jumping game under that
exact name (App Store id 1173688324), and App Store names are globally unique.

Ten characters matters more than it looks: iOS truncates the name under the
home-screen icon at roughly twelve characters. "FLIP — One Move at a Time"
would render as "FLIP — On…", which reads as a bug. "Flip Field" fits whole.

It also sidesteps the crowded "Flip + object" shelf (Flip Tiles, Tile Flip,
Flip Puzzles, Flippy Flip), several of which are the same game as this one.

Still confirm availability in App Store Connect before creating the record —
the name locks to it. Fallbacks: `Flip Field — Logic`, `Flip Field Puzzles`.

## Description (4000 max)

```
FLIP is a logic game stripped to one idea: turn every tile on.

Tap a tile and it flips — along with its neighbours. Which neighbours depends on
the tile: a cross flips the four around it, a row flips its whole row, a column
flips its whole column. Every move is its own undo, so nothing is ever lost,
only counted.

THREE MECHANICS, NOTHING ELSE
The first levels teach the cross on its own. Then rows arrive, then columns, and
from there the board mixes all three. There is nothing else to learn — the depth
comes from how the three interact, not from new rules arriving every week.

A REAL LIMIT
Each level allows four times the moves a perfect solve needs. Generous if you
can read the board, unforgiving if you are only tapping. Run out and you see
exactly how close you were.

EVERY LEVEL IS SOLVABLE
Levels are not scattered at random. Every board is checked by a solver before
you ever see it, and the shortest solution is known — which is what the move
limit and the star rating are measured against. There are no dead ends.

IT NEVER RUNS OUT
Nine hand-built levels teach the game, then it continues indefinitely, getting
harder as you go. Level 40 is as real a level as level 4.

A NEW ONE EVERY DAY
Daily Flip is one board a day, the same board for everyone, replayable until
midnight.

QUIET BY DESIGN
No timer. No lives. No energy. No coins. No account. No ads. No network — the
game does not connect to anything, and works the same in a tunnel as at home.

English and Ukrainian.
```

**One decision to confirm.** "Puzzle" is banned from the interface, but keywords
are never shown to anyone — they exist only so App Store search can match the
app. It is the single highest-traffic term in this genre, and dropping it makes
the game materially harder to find. It is included here on that basis; say the
word and it comes out, at a real cost to discovery.
